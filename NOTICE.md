# Project credits

This project originates in collaborative Representation of Signals and Inverse
Problems coursework at Centrale Lille. The supplied course README credits
P.-A. Thouvenin. The original boat/chessboard images and audio resources are
identified in `data/README.md`, with file hashes in `data/manifest.json`.

The rewritten implementation, documentation and plotting code are part of this
project. Original course sheets, exams, slide screenshots, article
PDFs and the course plotting helper are not included. The mathematical methods
and scientific articles are credited in `REFERENCES.md`.

The code license does not relicense the included course media, third-party
publications or software dependencies. PyWavelets provides the standard Bumps
and Blocks examples used in the original wavelet exercises.
